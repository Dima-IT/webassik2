 Assignment 2 - Advanced CSS (Flexbox & Grid)



Task 0 - Navigation Bar

In this task, I created a navigation bar using Flexbox.

First, I created a header with a logo on the left side and navigation links on the right side. I used display: flex to place the elements horizontally.

Then, I used justify-content: space-between to create space between the logo and navigation links. I also used align-items: center to vertically center all elements.

For the navigation links, I used Flexbox again and added gap to create equal space between the links.

Task 1 - Card Row

In this task, I created three cards for Marvel movies.

Each card contains a movie poster, title, short description, and button. I used Flexbox to display all three cards in one row.

I used gap to add equal space between the cards and flex: 1 to give them equal space.

I also added a hover effect. When the mouse is placed over a card, the card moves slightly up and a shadow appears.

 Task 2 - Page Layout with Grid Areas

In this task, I created a page layout using CSS Grid.

The layout contains a header, sidebar, main content, and footer. I used display: grid to create the Grid layout.

I created two columns using grid-template-columns. The sidebar takes one part of the available space and the main section takes three parts.

I also used grid-template-areas` to define the position of each section. The header is at the top, the sidebar is on the left, the main content is on the right, and the footer is at the bottom.

Task 3 - Image Gallery

In this task, I created a Marvel image gallery using CSS Grid.

The gallery contains nine Marvel images. I used display: grid and grid-template-columns: repeat(3, 1fr) to create three equal columns.



I also added a hover effect for the captions. The caption is hidden normally, but when I move the mouse over an image, the name of the character appears at the bottom.

Task 4 - Portfolio Page

In this task, I created a Marvel portfolio page and combined Flexbox and CSS Grid.

For the header and navigation bar, I used Flexbox to place the logo and navigation links horizontally.

For the main section, I used CSS Grid to create two columns. The movie projects are displayed on the left side and the information sidebar is displayed on the right side.

Inside the project cards, I used Flexbox with flex-direction: column to arrange the title, description, and button vertically.

Finally, I added a footer at the bottom of the portfolio page.

In this assignment, I practiced using Flexbox and CSS Grid to create different website layouts. I used Flexbox for navigation bars, cards, and alignment of elements. I used CSS Grid for page layouts and the image gallery.

I also learned how to use properties such as gap, justify-content, align-items, grid-template-columns, and grid-template-areas. I added simple hover effects to make the website more interactive.

This assignment helped me understand the difference between Flexbox and Grid and how they can be used together on the same website.
